# Run-condition templates

Goal: a "Use a template" menu in the routine run condition fields. It fills `conditionCommand` and `conditionWhen`.

- Pure module `run-condition-templates.ts` (renderer conversation feature): template list, `shellQuote`, `fillTemplate`.
- Quote: wrap in single quotes, replace `'` with `'\''`.
- Templates: new git commit, new file in a folder, web page changed, file exists. Placeholder templates ask for a value first.
- UI: inside the `port.runCondition` gate. Select menu, then an Input with Apply button for placeholder templates.
- i18n: `en` keys only.
- Agent tool: list the same commands in the `create_routine` description.
- Test: unit test for quoting and filling. Release note.

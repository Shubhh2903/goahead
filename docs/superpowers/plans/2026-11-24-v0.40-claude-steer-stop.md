# Claude steer while a tool runs, and Stop for a lost Claude turn

Goal: port upstream `cd254c408` (#14259) and `25dd7dcea` (#14228) into the Promise-style GoAhead code. No `effect`.

## Steer while a tool runs (`src/backend/claude-client.ts`)

- `ActiveTurn` gets `untakenSteerIds`, `hostToolCalls` (abort controllers), `personRequests` and `stopRequested`.
- `#steerTurn`: when a main-thread tool call is open and no question or write approval waits for the person, send the steer with `priority: "now"` and remember its uuid.
- `result`: remove the uuids that the result lists (`user_message_uuids`, else `user_message_uuid`). An interrupted result with an untaken steer and no Stop closes the open tool calls, aborts the open host tool calls, and keeps the turn open. The result of the steer's turn completes it.
- `#callDynamicTool` gives each host call an abort signal. `#requestUserInput` and `#requestWriteApproval` count as person requests.

## Stop for a lost turn

- `turn/interrupt` answers `{ turnActive: false }` when the named turn is not the active turn, also for a released thread. A failed query interrupt for such a turn is ignored. A Stop of the active turn sets `stopRequested`.
- Preview (v0.39): Stop of the active turn clears the preview at once (timer and shown preview), and no new preview starts after Stop.
- `agent-service.ts` `#interruptTurn`: a user Stop (no `mayStop`) that gets `turnActive: false`, for a turn that the lifecycle does not run or complete but the snapshot still shows, settles the turn as interrupted.
- `turn-lifecycle.ts`: `isCompleting(turnId)` and `settleLostTurn(...)`. The settle sends an empty `turn-text-preview` for the turn, so no preview stays.

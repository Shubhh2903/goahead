# Feature plan: "Recent activity" chat sort (v0.40 item 4)

Upstream: `e8ea17f94` (#10493). GoAhead had no "Sort chats" menu and no unread orders, so this adds the
minimal base: an order setting with two values, `manual` and `recent`. Unread orders are out of scope.

## Files
- `packages/ui/src/features/sidebar/sidebar-types.ts`: `SidebarChatOrder`, `SIDEBAR_CHAT_ORDERS`,
  `SIDEBAR_CHAT_ORDER_LABEL`, `sidebarChatOrderSortsSections`, `parseSidebarChatOrder`,
  `sortSidebarChatsByRecent`; props `chatOrder`, `onChatOrderChange`.
- `stores/data-store.ts`: sort `filteredChats` by activity in `recent`. `stores/layout-actions.ts`: a drop
  in `recent` appends. `sidebar-scope.ts`, `SidebarAgentRow.tsx`, `SidebarChannelRow.tsx`: `chatsDraggable`.
- `SidebarNav.tsx`: "Sort chats" submenu in the free-area context menu. `icons.ts`: `ArrowUpDown`.
- Desktop: `sidebar-chat-order-storage.ts` (localStorage, per device), `sidebar-preferences.ts`,
  `WorkspaceSidebar.tsx`.
- Mobile: `workspace/model/chat-order.ts` (type, parse), `sidebar-layout.ts` (`sortMobileChatsByRecent`,
  `order` argument), `settings/model/chat-order.ts` (SecureStore + zustand), `app/_layout.tsx` (load),
  `connected-screen.tsx` (Android `MenuView` submenu, iOS toolbar submenu).
- i18n (en only): `sidebar.order.*`, `mobile.agent.home.sort.*`. Notes: `changelog.d/`, `apps/mobile/changelog.d/`.

## Tests
- `sidebar-chat-order.test.ts` (ui): order with and without activity, unknown value reads as manual.
- `sidebar-storage.test.ts` (desktop): setting round-trip, bad value, blocked storage.
- Mobile: `sidebar-layout.test.tsx` (sort), `chat-order.test.ts` (setting round-trip, storage failure).

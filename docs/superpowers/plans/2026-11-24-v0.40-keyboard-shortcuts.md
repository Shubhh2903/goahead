# v0.40 Keyboard shortcut settings

Port of upstream 4b860db5a (#14167), trimmed to what GoAhead has. Renderer only, so no IPC change.

## Scope
Commands: globalSearch (Cmd+K), searchChat (Cmd+F), newAgent (Cmd+Shift+E), toggleSidebar (Cmd+B),
showShortcuts (Cmd+/). Fixed (read only): open settings.
Left out: new/previous/next thread, back/forward, focus composer (GoAhead has no thread
navigation, chat history, or composer focus hook). Mobile "Open Agent" App Intent (Swift): left out.

## Files
- packages/ui/src/features/settings/keyboard-shortcuts.ts: DOM-free rules (chords, defaults,
  reserved keys, conflict check, match, parse/serialize, label text). Own chord type: GoAhead has no talk-key.
- packages/ui/src/features/settings/KeyboardShortcutsSettings.tsx + keyboard-shortcuts.css: tab UI (recorder, reset).
- src/renderer/src/keyboard-shortcut-preference.ts: localStorage persistence + signal, matchesShortcut.
- src/renderer/src/features/settings/SettingsKeyboardTab.tsx, settings-tabs.ts, SettingsModal.tsx: new tab.
- src/renderer/src/features/window/workspace-shortcuts.ts: newAgent, toggleSidebar, showShortcuts handler; WorkspaceShell wiring.
- globalSearch: server-scope.tsx, WebWorkspace.tsx. searchChat: search-store.ts. Drop global-search-shortcut.ts.
- i18n en keys; ui package.json exports + icons (Keyboard); styles.css import; changelog.d/keyboard-shortcuts.md.

## Tests
- packages/ui/src/features/settings/keyboard-shortcuts.test.ts: refusal rules (invalid, reserved, taken),
  match by typed character, parse/serialize round trip, bad stored data.
- src/renderer/src/keyboard-shortcut-preference.test.ts: persistence, rebound key triggers the action
  at handler level (useWorkspaceShortcuts) while the old key does not.

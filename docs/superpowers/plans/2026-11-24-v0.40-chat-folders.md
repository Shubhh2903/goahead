# Feature plan: chat folders and sidebar filter (v0.40 item 1, Task 6)

## Upstream

- The brief names `ddb748b7f` (#14221). That commit adds **workspace folders to group chats** (file system
  paths in `channel_json`). It is not the sidebar folder feature. The sidebar folder feature is
  `c7edf4a07` (#4524, "Put sidebar folders inside folders"). This plan ports `c7edf4a07` and `4c2c80817`
  (#11925, the filter menu and the CPU fix). It does not port `ddb748b7f`.
- GoAhead already has flat sidebar "sections" (create, rename, delete, drag chats in). Upstream calls them
  folders and lets a folder hold folders, to three levels. This port does the same.

## Storage decision

- Upstream keeps the parent of a folder in the sidebar layout snapshot (`SidebarSection.parentId`), in the
  JSON file `sidebar-layout.json`. GoAhead does the same. No SQLite migration.
- The file stays `version: 2`. `parentId` is optional. A file without `parentId` loads as today's list.
  An older GoAhead reads the new file: its check reads only `id` and `name`, so it shows a flat list.
- A loaded `parentId` that names no folder, a cycle, or a fourth level is dropped on load (the folder goes
  up), and the file is not reset.

## Wire decision

- The released v1-v6 codecs project a section to `id` and `name`, so `parentId` does not cross them. No
  released codec, adapter or fixture changes.
- New capability `chat-folders-v1` in its own frozen file `team-protocol/chat-folders-v1.ts`, listed in
  `current.ts` and `optional-routes.ts`. One route: `POST /v1/chat-folders` with an empty body. It answers
  the whole layout with `parentId`. The host hides agents that the member cannot see, as for
  `/v1/sidebar-layout`.
- Scope of the first version: the desktop edits folders on the local host only. A joined host on the
  desktop and the web client keep today's flat list. The phone shows folders read-only: when the host
  advertises `chat-folders-v1`, the phone reads `/v1/chat-folders` and shows each folder with its path
  ("Parent / Name") in tree order. An older host gives the flat list. On `sidebar-layout-changed` the phone
  reads the route again.

## Interfaces

- `packages/contracts/src/ipc-sidebar-layout.ts`: `SidebarSection.parentId?`, `SIDEBAR_FOLDER_LEVELS = 3`,
  actions `create.parentId?` and `nest { sectionId, parentId, beforeSectionId }`, helpers
  `sidebarFolderParents`, `sidebarFolderAncestors`, `sidebarFolderHeight`, `sidebarFolderTreeOrder`,
  `sidebarFolderPath`.
- `src/backend/sidebar-layout-store.ts`: tree normalization on load and after each action; `create` with a
  parent; `delete` moves the chats and folders of the folder up one level; `nest`.
- `src/main/ipc/agent-inputs.ts`: parse `parentId` and `nest`. `src/main/team-api/route-chat-folders.ts`
  and its registration in `team-api-server.ts`.
- `packages/ui` sidebar: prop `foldersSupported`; folder path in the header; menu items "New folder
  inside" and "Move to" (top level or a folder); sibling-aware "Move up/down" and header drag with `nest`
  when folders are supported; a child folder hides while a parent is collapsed; filter menu
  (`SidebarFilterMenu.tsx`, `sidebar-list-filter.ts`): show all/agents/channels, unread, working, folders.
  Nothing drags while a filter is set. CPU fix: `content-visibility: auto` on sidebar rows.
- Renderer `WorkspaceSidebar.tsx`: `foldersSupported` only for the local host.
- Mobile: `sidebar-layout.ts` (`mobileFolderLayout`, path names), `mobile-workspace-context.tsx` (read the
  route when the capability is present).
- i18n (en only): folder words for section strings, `sidebar.folder.*`, `sidebar.filter.*`,
  `error.backend.sidebarFolder*`, `error.team.chatFoldersUnsupported`.
- Recent sort (Task 1) groups after the sort, so each folder shows its chats by recent activity.

## Tests (one file at a time)

- `src/backend/sidebar-layout-store.test.ts`: a saved layout with no folder loads as today's list; folder
  delete keeps its chats (they move to the parent, or to Unassigned at the top); nest depth limit.
- `packages/contracts/src/team-protocol/chat-folders-v1.test.ts`: codec keeps `parentId`, rejects bad input.
- `apps/mobile/src/features/workspace/model/sidebar-layout.test.tsx`: capability-absent path gives the flat
  list; with folders the path names show.
- `packages/ui/src/features/sidebar/sidebar-list-filter.test.ts`: the text filter matches the name and the
  last message; the menu filter by kind, state and folder; recent sort inside a folder.
